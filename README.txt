CONTENTS
- complete_practical.py: DataFrame, all 10 Pandas operations, and all 5 charts in one file.

HOW TO RUN
1. Install Python 3.
2. Open a terminal in this folder.
3. Install dependencies:
   pip install -r requirements.txt
4. Run the complete program:
   python complete_practical.py

You can also run the separate files individually:
   python dataframe_and_operations.py
   python five_charts.py

The code uses the same 15-student dataset and chart logic as the practical file.
